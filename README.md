# Portfolio Site

Portfolio personnel reconstruit en React (Vite).

## Structure

- `react-site/` : application React (Vite)
- `index.html`, `script.js`, `style.css` : anciens fichiers statiques

## Lancer en local

```bash
cd react-site
npm install
npm run dev
```

## Build

```bash
cd react-site
npm run build
```

## Fonctionnalités

- Navigation sticky avec liens d'ancrage
- Bascule thème clair/sombre (persisté via localStorage)
- Section projets, compétences avec barres animées, contact
- Design responsive
